## 二、手机端配置类型（platform）

新增字段 `platform`，取值三档：

| 取值 | 界面文案 | 生效范围 |
| --- | --- | --- |
| `all` | 通用 | 电脑端 + 手机端都下发（默认） |
| `pc` | 仅电脑端 | 仅电脑端下发 |
| `mobile` | 仅手机端 | 仅手机端下发 |

判定逻辑：请求带 `?platform=mobile|pc` 时以参数为准；不带则按 User-Agent 自动识别（含 Mobile/Android/iPhone/iPad 判为 mobile，其余 pc）。

排序规则：同一场次专属源优先 → 通用源次之 → 专属源再次，同级按 id 升序，保证录入顺序即展示顺序。

涉及接口：

- `GET /api/video/play?match_id=<id>&platform=<pc|mobile>` — 返回 `platform` 字段
- `GET /api/match?...`、`GET /api/videos?...` — 同步按客户端平台过滤
- `GET /api/admin/videos` — 列表返回 `platform`
- `POST /api/admin/videos/save` — 支持 `platform`、`kind=link`

用户端表现：手机端专属源会打上「手机端专属」标签；`link` 类型渲染为「打开新窗口」按钮，`embed` 走 iframe，`hls/mp4` 走 video + hls.js。

### 三种公网方案对比

| 方案 | 地址稳定性 | 是否需要域名/备案 | 适用 |
| --- | --- | --- | --- |
| Cloudflare Quick Tunnel（当前已启用） | 每次重启换随机子域，进程存活期间稳定 | 不需要 | 临时演示、验收 |
| Cloudflare Named Tunnel | 固定子域，永久稳定 | 需要一个已托管到 Cloudflare 的域名 | 长期在线（推荐） |
| 内网穿透服务（花生壳/ngrok 付费/cpolar） | 固定域名，付费版稳定 | 不需要 | 无域名时的长期方案 |

### 启动 / 停止隧道

- 启动：双击 `start_tunnel.bat`，窗口会打印本次公网地址，把它填进管理端「公网地址」并保存
- 停止：`taskkill /IM cloudflared.exe /F`
- 隧道进程独立于站点进程，关闭命令行窗口不影响；机器重启后需重新执行 `start_tunnel.bat`

### 升级为固定域名（长期在线）

1. 域名 NS 托管到 Cloudflare（免费套餐即可）
2. `tools\cloudflared.exe tunnel login`
3. `tools\cloudflared.exe tunnel create worldcup`
4. 配置 `%USERPROFILE%\.cloudflared\config.yml`：hostname → `http://127.0.0.1:8848`
5. `tools\cloudflared.exe tunnel route dns worldcup arena.你的域名.com`
6. 以服务方式常驻：`tools\cloudflared.exe service install`

完成后公网地址固定为 `https://arena.你的域名.com`，写入管理端「公网地址」即可。
